# Immutable builtin factor catalogues

Both JSON files use catalogue schema 2: explicit ordered IDs, name, original formula, syntax, source AST, formula version and source metadata. Every entry explicitly includes `execution_formula`: an execution string for the twelve GTJA interpretations, null otherwise. Missing fields and schema 1 are rejected. They are embedded with `include_str!`; workspace users cannot edit builtin definitions. GTJA source strings and Qlib source ASTs preserve their prior definitions exactly. The original `formula` remains unchanged. Both strings are exposed in FactorSpec/manifests and the audit explains each choice. `src/formulas.rs` validates catalogue versions, and the unified operator registry compiles both into explicit semantic operator IDs before execution.

Acceptance: `cargo test -p analytics-factor`; the original GTJA/Alpha158 golden fixtures must remain unchanged; the separate direct-formula completion fixture adds the twelve GTJA v5 entries. This folder contains source definitions, never generated market data. See the component README for provenance and numeric conventions.
