# 国泰君安191因子审计

## 当前契约：v5（2026-10-18）

版本 `gtja191-paper-2017+jfquant-audit-v5`：191个canonical ID全部具有可执行AST，隔离清单为空。
默认研究190项，排除依赖外部三因子数据的Alpha030；可显式选用全部191项。
12项原歧义式采用下面公开的JFQuant解释，**不声明原报告已无歧义或全部公式严格等价于原文**。
目录的`formula`保留原始字符串；可选`execution_formula`、AST、公式版本和manifest共同记录实际解释。
历史v4配置、缓存和模型不能冒充v5；原有178项在新190项中保持相对顺序，新增项按canonical顺序插入。

原报告：[李辰、刘富兵《基于短周期价量特征的多因子选股体系》（2017-06-15）](https://guorn.com/static/upload/file/3/134065454575605.pdf)，

## 12项显式解释

| 因子 | v5执行约定与依据/差异 |
|---|---|
| 010 | 将5放入滚动MAX，再做截面RANK；与DolphinDB函数体一致。 |
| 036 | CORR窗口6、SUM窗口2，再RANK；原报告标点错位，既有目录修正版及DolphinDB一致。 |
| 054 | 明确选STD窗口10，与CORR及DolphinDB一致；原报告没有指定该窗口。 |
| 127 | 滚动最高价12和外层MEAN12；这是明确补充的约定。DolphinDB函数体使用逐元素MAX，未照搬。 |
| 143 | SELF在每证券首个有效正收盘价处种子为1。上涨日乘简单收益（无+1），其他有效相邻日保持；空值日输出null保留状态，缺失后的首行不跨缺口比较。种子是额外约定。 |
| 146 | 补分母SMA的M=2，保留原报告分子的乘积及分母平滑量平方；不采用DolphinDB遗漏乘积并改MEAN的函数体。 |
| 157 | 顺序为DELTA5、RANK、负号、两层RANK、TSMIN2、SUM1、LOG、两层RANK、PROD1、TSMIN5，再加DELAY6/TSRANK5的负收益。外层MIN明确为时序，避免全样本取最小引入未来信息。 |
| 165 / 183 | 明确选尾部48/24日的R/S：以该窗口均值中心化，偏差逐项累加后取极差，整个极差除以该窗口样本STD。该窗口局部解释补齐SUMAC和极值维度，区别于DolphinDB跨股票取极值，也不把历史累计量误作有限窗口。常量窗口为null。 |

## Alpha030输入

多元OLS始终保留截距及MKT/SMB/HML全部预测量，响应为简单股票收益；不改成超额收益，且不自行推断无风险利率。
输入文件`three_factor_returns.json`在选定日频快照根目录；单文件行情使用其父目录。格式、单位和来源字段见
[storage接口](../storage/README.md#alpha030外部三因子输入)。原始来源必须声明市场及return_basis，用户需提供与研究市场相符的真实序列。
不从价量数据伪造MKT/SMB/HML，不自动填0/插值/前向填充；缺文件、缺日、null和损坏分别进入既有输入/样本策略。
三因子不按价格锚点或成交量单位缩放。Parquet因子页、原管道及原生日频年度研究均支持；来源元数据和字节进入缓存签名。
默认190项可在不具备这些输入时使用；全部191项配置见`workflow/templates/factors/gtja191-full.json`。

## 数值及验证边界

保留v4算子约定：WMA为归一化`0.9^lag`，SIGN(0)=0，HIGHDAY/LOWDAY最新值距离0，
RANK/TSRANK最大并列名次/n及尺度容差`1e-12*max(1,abs(a),abs(b))`，STD/COV样本分母n-1，
SMA首个有限输入为种子、系数M/N。普通滚动要求完整有限窗口；非法幂/零除/非有限结果为null。
FILTER条件回归保留成对有效观测；SEQUENCE为持续时间位置；嵌套lookback由AST组合。
Alpha028保留印刷版第二分母TSMAX(LOW,9)；Alpha149筛选最近252条交易行内条件配对观测。

`testdata/operator_golden.json`完整保留历史v4的179项数值，不覆盖更新来让测试变绿。
新增`gtja191_completion_expected.json`由独立直接NumPy公式产生，使用同一320日×6证券输入但不读取Rust AST；
两者合并比较全部191项的末3日。另有Alpha002、Alpha143种子/上涨/下跌/缺口/跨证券/未来隔离、R/S常量/缺口/窗口均值的手算测试。
Alpha030分别在Parquet检查及原生年度缓存中验证真实格式输入、空值、单位、来源变更与缓存失效，合成测试输入不作为真实行情发布。
这些检查验证公开的v5解释和算子数值，不能认证原报告未明确规定的含义。
Alpha064在既有合成面板末3日全为null，仍不把运行成功等同因子有有效值。
